1) Таблица character_anime_works содержит информацию 282К персонажах. Из какого они аниме, их именах и роли
Имеет 4 поля: 
- внешние ключи anime_mal_id - id аниме
- character_mal_id - id персонажа
- character_name - имя персонажа
- role - роль в сюжете, main либо supporting.

/ В поле с именем 115К уникальных значений, а main role/supporting role имеет соотношение 20/80 

Уникальный ключ - character_mal_id /


2) Таблица character_nicknames содержит альтернативные или фанатские прозвища персонажей, дополняющие набор данных о персонажах.
Имеет 2 поля - ключ character_mal_id (282K) и альтернативное прозвище nickname - (29К уникальных значений)

3) Таблица characters содержит основные сведения о каждом персонаже, включая имена, написание иероглифами кандзи, изображения, список избранного и биографии.
Имеет 6 полей:
- character_mal_id - уникальный ключ (282К)
- url - ссылка на страницу персонажа на MyAnimeList (210K)
- name - имя персонажа на английском (163K уникальных)
- name_kanji - имя персонажа на японском (154К уникальных, 26% [null])
- image - ссылка на изображение персонажа (у 11% вместо портрета ссылка на логотип MAL)
- favorites - количество пользователей, отметивших персонажа как любимого
- about - биографическая или описательная информация о персонаже

4) Таблица details - основные метаданные аниме, включая названия, жанры, студии, оценки, информацию об эпизодах и данные о трансляции. Самая важная в этом датасете.
Имеет следующие поля:
1. mal_id - id аниме (62.6К)
2. title - название на английском
3. title_japanese - название на японском
4. url - ссылка на страницу аниме на MyAnimeList
5. image_url - ссылка на постер аниме
6. type - формат аниме (ТВ-сериал, фильм, OVA и т. д.)
7. status - статус показа (Транслируется, Завершён, Ожидается)
8. score - оценка аниме пользователям по 10-бальной шкале
9. scored_by - число пользователей, оценивших данное аниме
10. start_date - дата начала показа аниме
11. end_date - дата окончания показа аниме
12. synopsis - краткое описание сюжета (18% [null])
13. rank - позиция в общем рейтинге аниме по оценке
14. popularity - рейтинг популярности на основе интереса пользователей
15. members - общее число пользователей, добавивших аниме в свои списки
16. favorites - число пользователей, отметивших аниме как любимое
17. genres - список жанров аниме (21% [])
18. studios - студии анимации, участвовавшие в производстве (40% [])
19. themes - тематические теги, описывающие сюжет (например: школа, романтика) (41% [])
20. demographics - целевая аудитория (например, Shounen, Seinen) (63% [])
21. source - первоисточник (например, манга, ранобэ, оригинал)
22. rating - возрастной рейтинг (например, PG-13, R)
23. episodes - общее число эпизодов
24. season - сезон выхода (зима, весна, лето, осень) (78% [null])
25. year - год выхода
26. producers - компании-продюсеры (53% [])
27. explicit_genres - жанры для взрослой/ограниченной аудитории (если есть) 
28. licensors - компании-лицензиары для дистрибуции (82% [])
29. streaming - официальные стриминговые платформы, где доступно аниме (87% [])

5) Таблица favs - фиксирует избранное пользователей (аниме, персонажей и создателей), позволяя анализировать популярность и предпочтения.
- username — имя пользователя, добавившего объект в избранное; может быть объединено с файлом profiles.csv по полю username (246К)
- fav_type — тип объекта (аниме, персонаж или личность), добавленного пользователем в избранное.
- id — идентификатор объекта; объединяется с файлом details по полю mal_id (если fav_type='anime'), с characters по полю character_mal_id (если fav_type='character') и с person_details по полю person_mal_id (если fav_type='person').

6) Таблица person_alternate_names - перечисляет альтернативные имена или псевдонимы сотрудников или актеров озвучки
- person_mal_id — уникальный идентификатор персоны на MyAnimeList; внешний ключ для person_details по этому полю
- alt_name — альтернативное имя, сценический псевдоним или имя в латинской транскрипции, используемое данной персоной

7) Таблица person_anime_works - сопоставляет участников съемочной группы с аниме, над которыми они работали.
- person_mal_id — id относящийся к участнику съемочной группы
- position — роль или должность участника в создании аниме
- anime_mal_id — id аниме

8) Таблица person_details - подробная информация о сотрудниках и актерах озвучивания. Служит основным справочным источником для всех таблиц, связанных с персоналиями.
Имеет следующие поля:
1. person_mal_id - id персоны на MyAnimeList; первичный ключ, связывается с другими таблицами о персонах (person_voice_works, person_anime_works, person_alternate_names) (90К)
2. url - прямая ссылка на профиль персоны на MyAnimeList
3. website_url - официальный личный или профессиональный сайт персоны
4. image_url - ссылка на фото персоны
5. name - полное имя
6. given_name - имя
7. family_name - фамилия
8. birthday - дата рождения
9. favorites - число пользователей, отметивших персону как избранную
10. about - биографическое описание или описание карьеры

9) Таблица person_voice_works - связывает актеров озвучивания с персонажами и аниме.
1. person_mal_id - id персоны 
2. role - тип роли (главная или второстепенная)
3. anime_mal_id - id аниме
4. character_mal_id - id персонажа
5. language - язык, на котором персона озвучивала роль (японский - 42%, английский - 19%)

10) Таблица profiles - хранит профили пользователей (пол, местоположение, количество аниме по статусам: «смотрю», «просмотрено», «отложено» и т. д.)
1. username - уникальный ник пользователя; первичный ключ
2. gender - пол пользователя (указанный им самим, 51% [null])
3. birthday - дата рождения
4. location - указанное пользователем географическое местоположение
5. joined - дата регистрации на платформе
6. watching - число аниме, которые пользователь смотрит в данный момент
7. completed - число аниме, которые пользователь досмотрел
8. on_hold - число аниме, просмотр которых временно приостановлен
9. dropped - число аниме, которые пользователь бросил смотреть
10. plan_to_watch - число аниме, которые пользователь планирует посмотреть

11) Таблица ratings - содержит данные о взаимодействии пользователей с аниме, включая оценки, статус просмотра и прогресс просмотра серий.
1. username - уникальный ник пользователя
2. anime_id - id аниме
3. status - статус просмотра аниме пользователем (например: смотрю, завершено, отложено, брошено, планирую посмотреть)
4. score - числовая оценка, поставленная пользователем аниме
5. is_rewatching - булевое значение, указывающее пересматривает ли пользователь аниме в данный момент
6. num_watched_episodes - число просмотренных пользователем эпизодов

12) Таблица recommendations - описывает, какие аниме были рекомендованы к просмотру ссылаясь на текущее аниме
1. mal_id - id аниме
2. recommendation_mal_id - id рекомендованного аниме на MyAnimeList (связанного с базовым)

13) Таблица stats - агрегированная статистика по аниме — оценки, рейтинги, популярность, число пользователей в списках. 

1. mal_id - id аниме
2. watching - число пользователей, смотрящих аниме в данный момент
3. completed - число пользователей, завершивших просмотр аниме
4. on_hold - число пользователей, временно приостановивших просмотр
5. dropped - число пользователей, бросивших просмотр до завершения
6. plan_to_watch - число пользователей, планирующих посмотреть аниме
7. total - общее число пользователей, добавивших аниме в свои списки
8. score_1_votes - число пользователей, поставивших оценку 1/10
9. score_1_percentage - процент от всех голосов, составляющих оценку 1/10
