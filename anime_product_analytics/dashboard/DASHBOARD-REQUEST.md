# Dashboard Request — «Во что вкладывать контент-бюджет»

## Для кого и зачем

- **Аудитория:** продюсер стримингового сервиса и рекрутёр, который смотрит портфолио аналитика данных.
- **Решение:** какие аниме-сериалы и первоисточники стоит покупать или заказывать, если смотреть на удержание зрителей, а не только на популярность.
- **Где смотрят:** Tableau Public, публичная ссылка в резюме, в основном с ноутбука.
- **Язык:** все подписи, заголовки и подсказки на русском.

## Данные

CSV лежат в `data/`, их выгрузил `src/export_tableau.py` основного проекта:

1. `tableau_titles.csv` — 1 101 TV-сериал 2020–2025 годов, Finished Airing, started ≥ 1000. Одна строка — один сериал.
   Поля: mal_id, title, start_year, source, main_genre, episodes, members, started, audience_quartile (Q1 малые … Q4 крупные), conversion_to_start, completion_rate (= completed / total), favorites_rate, ep3_retention, score_combined, segment, title_type.
   - segment: Флагманы 165 / Надёжный просмотр 188 / Нишевые любимчики 203 / Остальные 545.
   - title_type: Дебют 814 / Продолжение 287.
2. `tableau_episode_retention.csv` — длинный формат: mal_id, episode (1–12), retention, title, segment, source, title_type. 684 сериала ровно на 12 серий, 8 208 строк.

## Что должно быть на дашборде

- **KPI вверху:**
  - число сериалов в текущем разрезе;
  - медианный ep3_retention;
  - доля продолжений.
- **Кривая удержания по сериям 1–12** с разбивкой по сегментам. Главный вывод: 60% потерь приходится на первые 3 серии, к 3-й серии остаётся 84,4%.
- **Scatter «conversion_to_start × completion_rate»:** цвет — сегмент, размер точки — started.
- **Первоисточник × ep3_retention** с переключателем квартиля аудитории. Вывод: внутри квартилей разница между первоисточниками почти исчезает, решает масштаб, а не первоисточник.
- **Фильтры:** start_year, title_type, source.

## Ограничения

- Все цифры в подписях берутся только из этих CSV, ничего не выдумывать.
- Branding: нейтральная палитра, без логотипов.
- Итог — `.twbx`, который открывается в Tableau Public 2026.2 (Mac) и публикуется через File → Save to Tableau Public As…

## Сверка цифр с CSV (проверено 16.09.2026)

- **84,4%** — медиана retention на 3-й серии по 684 сериалам из `tableau_episode_retention.csv`.
- **60%** — (1 − медиана на 3-й серии) / (1 − медиана на 12-й серии) = 0,156 / 0,260 ≈ 0,600; потери считаются от 100%. Если брать среднее вместо медианы, выйдет 63%, поэтому на кривой нужна медиана.
- **KPI «медианный ep3_retention»** по `tableau_titles.csv` при всех фильтрах равен 84,2% (1 097 сериалов с непустым значением, у 4 пусто). Это не то же самое, что 84,4% на кривой: там только сериалы ровно на 12 серий. Подписи не должны смешивать эти две цифры.
- В `tableau_episode_retention.csv` 36 пустых retention у 23 сериалов, все на сериях 5–11. Серии 1–3 и 12 заполнены у всех 684.
