# Во что вкладывать контент-бюджет - PRD

## Overview

- **Задача:** помочь продюсеру стримингового сервиса решить, какие аниме-сериалы и первоисточники покупать или заказывать. Смотрим на удержание зрителей, а не только на популярность.
- **Аудитория:** продюсер (принимает решение) и рекрутёр, который смотрит портфолио аналитика. Дашборд должен читаться без знания проекта: заголовок каждого графика - это вывод, а не название метрики.
- **Где смотрят:** Tableau Public, публичная ссылка в резюме, в основном с ноутбука. Макет под десктоп.
- **Язык:** все заголовки, подписи осей, легенды, фильтры и tooltip на русском.
- **Обновление:** статичный снимок, без расписания. Данные меняются только при повторном запуске `src/export_tableau.py` и перепубликации.
- **Разрез данных:** TV-сериалы 2020–2025, `status == 'Finished Airing'`, `started >= 1000`.

### Источники

1. `data/tableau_titles.csv` - 1 101 строка, одна строка = один сериал. Поля: `mal_id`, `title`, `start_year`, `source`, `main_genre`, `episodes`, `members`, `started`, `audience_quartile`, `conversion_to_start`, `completion_rate`, `favorites_rate`, `ep3_retention`, `score_combined`, `segment`, `title_type`.
2. `data/tableau_episode_retention.csv` - 8 208 строк, длинный формат (`mal_id`, `episode` 1–12, `retention`, `title`, `segment`, `source`, `title_type`). Только 684 сериала ровно на 12 серий.

Связь между источниками - по `mal_id` (relationship). В `tableau_episode_retention.csv` нет `start_year`, поэтому без связи фильтр по году на кривую не подействует.

## KPIs

Плитки в верхней строке, пересчитываются от всех фильтров.

1. **Сериалов в разрезе** - `COUNTD([mal_id])` по `tableau_titles.csv`. При всех фильтрах = 1 101.
2. **Медианный ep3_retention** - `MEDIAN([ep3_retention])` по `tableau_titles.csv`, формат `0,0%`. При всех фильтрах = 84,2% (1 097 сериалов, у 4 значение пустое). Подпись плитки должна явно говорить «все сериалы разреза», чтобы не путать с 84,4% на кривой.
3. **Доля продолжений** - `SUM(IF [title_type] = 'Продолжение' THEN 1 ELSE 0 END) / COUNTD([mal_id])`, формат `0%`. При всех фильтрах = 26% (287 из 1 101).

## Visualizations

1. **Кривая удержания по сериям** - line chart, ось X `episode` (1–12, дискретно), ось Y `MEDIAN([retention])` в %, линия на каждый `segment` + жирная линия «Все сериалы». Источник - `tableau_episode_retention.csv`.
   - Агрегат - **медиана**, не среднее: на среднем доля потерь в первых 3 сериях выходит 63%, а не 60%.
   - Аннотация на 3-й серии: «к 3-й серии остаётся 84,4%, это 60% всех потерь за 12 серий».
   - В подзаголовке оговорка «684 сериала ровно на 12 серий».
   - Tooltip: сегмент, серия, медианный retention, число сериалов.
2. **Конверсия в старт × досмотр** - scatter, X `conversion_to_start`, Y `completion_rate` (оба в %), цвет `segment`, размер `started`, одна точка = один сериал. Источник - `tableau_titles.csv`.
   - Tooltip: `title`, `start_year`, `source`, `segment`, `title_type`, `started`, `conversion_to_start`, `completion_rate`, `ep3_retention`.
3. **Первоисточник × удержание на 3-й серии** - горизонтальный bar chart, `source` по оси Y, `MEDIAN([ep3_retention])` по оси X, сортировка по убыванию. Источник - `tableau_titles.csv`.
   - Переключатель квартиля аудитории: параметр со значениями «Все», «Q1 малые», «Q2», «Q3», «Q4 крупные», фильтр через calculated field по `audience_quartile`.
   - Вывод в заголовке: «внутри квартиля разница между первоисточниками почти исчезает - решает масштаб, а не первоисточник».
   - Рядом с баром или в tooltip - число сериалов в столбце, т к у мелких источников (`Book` 1, `Web novel` 2, `Music` 6) медиана шумная.

## Filters

Применяются ко всем листам (кривая получает `start_year` через связь по `mal_id`).

- **Год старта** - `start_year`, multi-select dropdown или range slider, 2020–2025.
- **Тип тайтла** - `title_type`, single-select с «Все» (Дебют / Продолжение).
- **Первоисточник** - `source`, multi-select dropdown, 14 значений.

## Additional Notes

- **Цифры только из CSV.** Все числа в заголовках и аннотациях сверены 16.09.2026: 84,4% и 60% - медианы по `tableau_episode_retention.csv`, 84,2% - медиана `ep3_retention` по `tableau_titles.csv`. Эти две цифры не смешивать в одной подписи.
- **Статичные выводы в заголовках** верны только при всех фильтрах. Если фильтр изменён, заголовок-вывод может не совпасть с графиком - либо делать числа в аннотациях динамическими, либо в подписи указать «при всех фильтрах».
- **Пропуски:** 4 пустых `ep3_retention` в `tableau_titles.csv`; 36 пустых `retention` у 23 сериалов на сериях 5–11. Медиана их игнорирует, отдельно не обрабатываем.
- **Квартили** `audience_quartile` посчитаны по всем 1 101 сериалам и при фильтрах не пересчитываются.
- **Доля продолжений при фильтре по типу** станет 0% или 100% - это ожидаемо.
- **Цвета:** нейтральная палитра, без логотипов. Сегменты - 4 фиксированных цвета, одинаковых на кривой и scatter; «Остальные» - приглушённый серый.
- **Порядок сегментов** в легендах: Флагманы → Надёжный просмотр → Нишевые любимчики → Остальные.
- **Форматы:** доли в процентах с запятой (`84,4%`), счётчики с пробелом-разделителем тысяч (`1 101`).
