## Santander: отток клиентов банка

- На уровне клиента оттока почти нет: когорты удерживают 96-100% активных клиентов, потому что текущий счёт никто не закрывает. Отток живёт на уровне продуктов
- У зачисления пенсии 55,8% «уходов» - мигание флага (1 → 0 → 1). Без поправки отток по зарплатно-пенсионным продуктам завышается примерно вдвое
- Опасное окно - третий-четвёртый месяц жизни: отток продукта растёт с 2,11% в месяц на k=1 до 3,22% на k=4
- Cross-sell защищает только внутри сегмента, в агрегате вывод переворачивается (парадокс Симпсона)

## MyAnimeList: контент-бюджет стримингового сервиса

- 60% потерь зрителей приходится на первые три серии
- `ep3_retention` повторяет `completion_rate` со Спирменом 0.90 и известен на 9 недель раньше, по нему можно решать о продлении
- Сиквелы и дебюты нельзя сравнивать по `completion_rate`: 92.8% аудитории сиквела уже досмотрели прошлую часть
- Флагманы по охвату и удержанию - экранизации популярной манги, оригинальные проекты попадают туда в 5% случаев

## Телеграм-канал Артемия Лебедева

- Больше всего реакций собирают авторские размышления, у постов с видео реакций на 68-70% меньше
- Размышления с вопросом в тексте комментируют на 44-46% чаще
- Пока комментарии были платными, комментариев на 1000 просмотров было в 6,5 раза меньше, а реакций столько же
- Результаты оформлены [письмом автору канала](lebedev_tg_research/letter/letter.pdf)
