# Показатели вовлечённости в телеграм-канале Артемия Лебедева

Исследование факторов, влияющих на реакцию аудитории (реакции, комментарии, пересылки) в телеграм-канале медийной персоны. Результаты оформлены письмом автору канала. Канал — [@temalebedev](https://t.me/temalebedev), выборка из 2279 постов с 1 октября 2024 по 30 сентября 2026 года.

## Структура репозитория

| Файл | Что в нём |
|---|---|
| `lebedev_tg_research.ipynb` | Всё исследование: очистка, признаки, сравнение медиан с бутстрап-ДИ, отрицательная биномиальная регрессия с проверкой на поздних постах, выводы и ограничения. Краткое описание и главные результаты — в первой ячейке. |
| `letter/letter.pdf` | Письмо Артемию Лебедеву (исходник `letter/letter.md`). |
| `letter/make_charts.py` | Графики для письма. Числа в нём взяты из выводов ячеек ноутбука. |
| `scripts/01_fetch.py` | Выгрузка постов канала через Telegram API → `data/raw_api.parquet`. |
| `scripts/01b_fetch_links.py` | Адреса ссылок в постах, включая спрятанные под словами → `data/links.parquet`. |
| `scripts/02_clean.py` | Очистка, склейка альбомов, разметка типа поста → `data/posts.parquet`. |
| `scripts/swear_roots.txt` | Корни мата для признака `swear`. Во всех выводах мат замаскирован. |
| `data/tone_manual.csv` | Ручная разметка тона 50 заголовков для проверки словаря. |

## Данные

Выгрузка сделана 9 октября 2026 года. Файлы `raw_api.parquet`, `links.parquet` и `posts.parquet` можно скачать по ссылке [архив на Google Drive](https://drive.google.com/file/d/1zj8qjNIzMdLZiJ1-SZVkpnw7vgjTIpl7/view?usp=drive_link).

Чтобы перезапустить ноутбук, распакуйте архив в папку `data/`. Новая выгрузка скриптами `01_fetch.py` и `01b_fetch_links.py` даст немного другие числа, так как у старых постов продолжают расти просмотры и реакции.

## Как запустить

```
python3.14 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/02_clean.py        # если data/posts.parquet нужно пересобрать
.venv/bin/jupyter lab lebedev_tg_research.ipynb
```

Для новой выгрузки нужны свои ключи Telegram API в `.env` (`TG_API_ID`, `TG_API_HASH`), скрипты `01_*` запускаются вручную и после работы завершают сессию.
